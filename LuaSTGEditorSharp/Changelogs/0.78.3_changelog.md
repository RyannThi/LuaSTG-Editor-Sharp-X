## LuaSTG Editor Sharp X - 0.78.3
## Features

* Added the "Create Simple Object" node. Acts like a simple enemy but as a normal object.
* Plugin DLLs will now unlock themselves automatically. No more plugin errors!

* Changed the "Call Function" node to be a leaf node.
* Removed the single instance restriction.

## Fixes

* Fixed the styling (color themes) of the "Add File" edit window.
* Fixed RichText Render node position edit window.
